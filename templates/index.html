Workflow

How Kerno works

Three simple steps to transform repository friction into a clear contribution roadmap.

1

Paste a repository

Enter any public GitHub URL (e.g., pallets/flask or full HTTPS link) into the search bar.

2

Live fact extraction

Kerno queries the GitHub REST API to scan actual manifests (pyproject.toml, package.json), file trees, and READMEs.

3

Explore your guide

Google's Gemma 4 synthesizes a grounded guide, file breakdown, verified setup commands, and contribution suggestions.

Powered by Google Gemma 4 & Public GitHub Data

Kerno retrieves public repository metadata, file trees, and configuration files strictly through the standard GitHub REST API. Explanations and suggestions are synthesized by Google's open-weight Gemma 4 (gemma-4-31b-it) under strict grounding rules to prevent hallucinated files, tools, or issues.
